# C++ and DSA practice

My daily C++ practice. I push whatever I solve the same day I solve it, so this
is a log of the reps rather than a polished portfolio.

## Folders

| Folder | What's in it |
| --- | --- |
| `basic` | Input/output, data types, ASCII, modulus, simple interest |
| `conditional` | if/else, relational operators, boolean type, validation |

Standalone files sit at the root until there are enough of them to make a folder.

## Running any of these

```bash
g++ filename.cpp -o filename
./filename
```
